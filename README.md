# BeaconTrace-HowdyHack-2026
BeaconTrace is an HLK LD2450 Driven Targetting Device inspired off of various similar projects using the exact radar module.
This project is intended as a practice of hardware implementation and proof of concept for a bodily detection device in low-visibility/obstructed environments within situations of disaster relief and emergency rescue.
LLM-driven logic; human review recommended prior to use.
